feat: Improve UI/UX across the application

This commit introduces several UI/UX enhancements and bug fixes:

- **Enhanced Mobile Notifications:**
  - Refactored `FollowRequestNotification` component to support inline and button display modes.
  - Updated `Header` to provide an inline-expanding notification list in the mobile menu, improving user flow.

- **Responsive Post Layout & Interactions:**
  - Fixed image overflow in `UserPostCard` by removing problematic negative margins from Swiper containers.
  - Redesigned reaction buttons in `UserPostCard` and `SinglePostPage` to use geometric line-style icons (LIKE, INSIGHTFUL, THANKS, HAHA) instead of text, improving visual appeal and saving space.
  - Implemented responsive layout for reaction buttons, ensuring they remain on a single line with text wrapping and responsive font sizes, preventing overflow on various screen sizes.

- **Improved Profile Page Responsiveness:**
  - Addressed follow button overflow in `ProfileView` by implementing a responsive layout for the profile header, ensuring proper display on smaller screens.
